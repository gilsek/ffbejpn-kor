# Exvius KR (FFBE 일본판 한국어 오프라인) v0.1.0

일본판 FINAL FANTASY BRAVE EXVIUS 11.0.0을 **서버 없이 혼자 플레이**할 수 있게 만든 비공식 한국어 오프라인 앱입니다.
영문판 오프라인 프로젝트 [Exvius Offline](https://github.com/Elvlin/exvius-offline)의 구조를 바탕으로 일본판에 맞게 옮기고 한국어로 번역했습니다.

제작: 길섹

## 설치 조건
- Android 5.0 이상, 64비트 ARM(arm64-v8a) 기기
- 여유 공간 **약 18GB** (게임 데이터 약 15GB + 내려받는 동안 쓰는 임시 공간)
- 첫 실행 때 게임 데이터 약 14.6GB를 내려받습니다. **Wi-Fi 연결을 권장합니다.**
- 시험한 기기는 Android 15 태블릿(Lenovo TB373FU) 1대뿐입니다. 다른 기기에서는 문제가 있을 수 있습니다.

## 설치 방법
1. [Releases](https://github.com/gilsek/ffbejpn-kor/releases/latest)에서 `ExviusKR-v0.1.0.apk`를 받아 설치합니다. (알 수 없는 출처 앱 설치를 허용해야 합니다.)
2. 앱을 실행하면 게임 데이터를 내려받습니다. 화면을 꺼도 알림으로 진행되며, 중간에 끊기면 이어서 받습니다.
3. 다운로드가 끝나면 게임이 시작됩니다. 이후에는 인터넷 없이 플레이할 수 있습니다.

데이터 팩(`jpkr-data-*.zip`)은 앱이 알아서 받으므로 직접 받을 필요가 없습니다.

## 들어 있는 것
- 오프라인 서버 에뮬레이션(로그인·스토리·이벤트·소환·상점)

## 알려진 문제
- 버튼·그림 안에 그려진 일본어 글자는 일부만 한국어로 바뀌었습니다.
- 일부 이벤트와 퀘스트는 들어갈 수 없거나 보상이 원본과 다를 수 있습니다.
- 드물게 「通信エラー」(통신 오류)가 뜰 수 있습니다. 다시 시도하면 대부분 넘어갑니다.
- 번역은 기계 번역 초벌에 검수를 거쳤지만 어색한 문장이 남아 있을 수 있습니다.

## 면책
- 이 프로젝트는 비공식·비영리 팬 작업이며 SQUARE ENIX 및 alim과 관계가 없습니다.
- FINAL FANTASY BRAVE EXVIUS와 관련된 모든 권리는 원 권리자에게 있습니다.
- 권리자의 요청이 있으면 내려갈 수 있습니다. 사용에 따른 책임은 사용자에게 있습니다.
